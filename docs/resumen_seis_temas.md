# NEXO y las seis unidades

| Unidad | Aplicación |
|---|---|
| 1 · Idea y arquitectura | Catálogo B2B, configuración de equipos y solicitud de propuesta; perfiles y capas |
| 2 · HTML y CSS | Catálogo, planes, fichas, formularios y diseño responsive |
| 3 · JavaScript y DOM | Filtros, validación, selección y orden de agentes, flujo ilustrativo |
| 4 · PHP y MySQL | Usuarios, sesiones, configuraciones y solicitudes persistentes con PDO |
| 5 · POO | UserRepository y BusinessRepository, constructor con PDO y encapsulación |
| 6 · Responsive y AJAX | Media queries, peticiones Fetch/JSON y mensajes de estado |

Node.js es opcional en el enunciado y no forma parte del servidor. Las herramientas opcionales de pruebas no son necesarias para ejecutar la aplicación.
