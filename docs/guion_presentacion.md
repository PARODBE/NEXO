# Guion de presentación

Duración orientativa: 7-9 minutos.

1. **Idea y objetivo (1 minuto).** Explicar el recorrido empresa → catálogo → equipo → solicitud de propuesta. Aclarar que es un prototipo comercial académico con servicios y precios ilustrativos.
2. **HTML y CSS (1 minuto).** Abrir el catálogo y una ficha, reducir el ancho de ventana y explicar estructura semántica, Grid/Flexbox y media queries.
3. **DOM y AJAX (1 minuto).** Buscar una especialidad y filtrar una categoría. Mostrar la petición Fetch y el JSON del catálogo en Network.
4. **Registro y configurador (2 minutos).** Crear una cuenta, elegir un plan, seleccionar y ordenar agentes y guardar. Recargar y comprobar que se conserva la selección y el orden.
5. **CRUD y permisos (1 minuto).** Editar el objetivo y modificar el equipo. Explicar que otra cuenta no puede abrir esa configuración. Mostrar la confirmación de eliminación sin borrar el ejemplo principal.
6. **Solicitud (1 minuto).** Abrir el formulario con la configuración propia y enviarlo con datos ficticios. Consultar la solicitud en la cuenta y aclarar que no se cobra ni se envía correo.
7. **Código y entrega (1 minuto).** Mostrar BusinessRepository, consulta preparada, hash de contraseña y CSRF. Enseñar SQL, README, documentación y verificación. Node.js es opcional.

Antes de presentar: iniciar XAMPP, importar nexo.sql, revisar el puerto y usar datos ficticios. No mostrar contraseñas o credenciales de base de datos.
