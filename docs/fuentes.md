# Referencias y recursos

La interfaz utiliza identidades geométricas realizadas con HTML/CSS, sin fotografías o identidades de personas reales. El catálogo y los planes son propuestas de producto para un ejercicio académico. No se presentan empresas, testimonios, pedidos o resultados reales como prueba comercial.

Referencias de las tecnologías empleadas:

- **PHP, PDO:** https://www.php.net/manual/es/book.pdo.php.
- **PHP, password_hash:** https://www.php.net/manual/es/function.password-hash.php.
- **PHP, sesiones:** https://www.php.net/manual/es/book.session.php.
- **MDN, Fetch API:** https://developer.mozilla.org/es/docs/Web/API/Fetch_API.
- **MDN, media queries:** https://developer.mozilla.org/es/docs/Web/CSS/CSS_media_queries/Using_media_queries.

Los nombres, descripciones, flujos ilustrativos y precios del catálogo son contenido de demostración creado para este proyecto; no constituyen una oferta contractual ni se atribuyen a un proveedor externo.
